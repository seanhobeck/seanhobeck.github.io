Projects

tapi

A POSIX-compliant C99/17 testing framework with runtime-based mocking for various architectures, some of which include: x86, amd64, armth, and aarch64. Made to support proper output and stream capturing, allowing developers to create quick and easy unit or integration tests for low-level software.

mapi

A research-oriented C++20 framework exploring PEB traversal, manual PE exporting, compile-time/runtime string transformation, and SIMD-assisted hashing. Written to explore windows internals and how modern antivirus and security software analyze binaries. Also used in an educational red-teaming competition bringing the first win to my team in 22 years at my high school.

View Project

lit

A localized, linear git-like version control system written in C99, focused on learning more about repositories, file tracking, snapshots, and how version control systems work internally. No external dependencies were used, written POSIX-compliant for use across any modern operating system.

View Project

lzd

A lazy worker-thread disassembler for big-endian ELF binaries written in C17 using ncurses as a UI and capstone. A light-weight reverse-engineering and binary exploitation tool for security analysts. Created during the Feburary 2026 Deerhacks competition at the University of Toronto Mississauga.
